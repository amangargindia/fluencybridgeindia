  • Subject - Jo action karta hai (Doer)

2. The Core Concept

English sentence ka ek basic dhancha (structure) hota hai: Subject + Verb + Object.

Object wo hota hai jispar verb (kaam) ka direct asar padta hai. Lekin kabhi kabhi, ek sentence mein do objects aa jate hain: ek Direct Object aur ek Indirect Object. Aisa zyadatar tab hota hai jab hum kisi ko kuch dete hain batate hain ya dikhate hain.

3. Direct Object

Ye wo asli cheez ya insaan hai jo action ko seedha receive karta hai.

Trick to find it:

Verb (Action word) ke aage "Kya?" (What?) ya "Kisko?" (Whom?) lagakar sawal pucho.

  • Sentence: "Rahul kicked the ball."
    • Kaam kya hua? -> Kicked.
    • Rahul ne kya kick kiya? -> the ball.
    • Result: "the ball" is the Direct Object.

4. Indirect Object

Ye wo insaan janwar ya cheez hai jiske liye kaam kiya gaya ya jisko direct object receive hua.

Trick to find it:

Verb ke aage "Kiske liye?" (For whom?) ya "Kisko mila?" (To whom?) pucho.

Important Rule: Indirect object hamesha Direct Object ke PEHLE aata hai bina kisi 'to' ya 'for' ke.

  • Sentence: "Neha gave Rohan a book."
    • Kya diya? -> a book (Direct Object).
    • Kisko mila book? -> Rohan (Indirect Object).

5. Top Mistakes

Mistake 1: Prepositional object ko Indirect Object man lena.

Galat Soch: Sentence "I gave a book to Rohan" mein 'Rohan' indirect object hai.

Sahi Logic: Grammatically yahan 'Rohan' ek preposition ('to') ka object hai. True indirect object tabhi banta hai jab sentence "I gave Rohan a book" ho. Meaning bilkul same hai par grammar ka construction alag ho jata hai.

Mistake 2: Subject Complement ko Direct Object man lena.

Example: "He is a doctor."

Sahi Logic: Yahan koi action nahi ho raha. 'Is' ek linking verb hai. Toh 'doctor' direct object nahi hai. Wo bas subject (He) ki hi pehchan bata raha hai isliye ise Subject Complement kehte hain.

6. Advanced Nuances

  • Pronoun Placement Rule: Agar aapka Direct Object ek pronoun hai (jaise 'it' ya 'them') toh aap standard (bina 'to' wala) Indirect Object structure use nahi kar sakte. Aapko 'to' lagana hi padega.
    ❌ Wrong: "Give him it."
    ✅ Right: "Give it to him."
  • Verbs that take two objects (Dative Verbs): Har verb do objects nahi le sakta. Kuch specific verbs hi allow karte hain. Yaad rakhne wale common words hain:
    give, buy, bring, send, show, teach, tell, lend, offer, make, cook, promise.
